# Credit Card Check
## summery 
This program takes in credit card numbers and verifies them.
## tools 
### tool 1
Takes in a credit card number as an array and returns true or false.
### tool 2
Takes in a array of credit card numbers (nested) and returns an array all the invalid numbers (nested). additionally, this array is stored globally for later use.
### tool 3
Takes in an array of invalid credit card numbers (obtained with tool 2) and returns an array of company names that issued the invalid numbers.
